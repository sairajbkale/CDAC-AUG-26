Answer:

200(ok),201(created),204(no content) is the status code the server returns on success and 400-499 is family of codes that

3. Name the three types of CSS and say where each is written. If all three colour the same paragraph differently, which 
wins? Which type would you use for a style shared by four pages, and why?
Answer:
There are three types of CSS named as : Inline (Written inside the tag of html),Internal (Written inside the head section
of html program using <style> tag),External CSS (Written in separate file and connect it with html using <link> tag with
relation as "stylesheet")
If all three CSS types are used to color a paragraph differently then the top priority will be to inline css then internal 
css and at last external css.For style which will be shared by four pages , i will use external css to achieve modularity 
because using external css, i need to create only one file of css for my program of 4 pages.

5. Explain padding and margin with a small drawing of a <div> showing content, padding, border and margin. What does 
box-sizing: border-box change?
Answer:
Padding is used when we want space between border and the elements inside the border , margin is used when we want space 
outside the border.box-sizing:border-box helps in ensuring that height and width of element include its border and padding 
that makes the size of the element predictable.

8. Explain the four values of the CSS position property (static, relative, absolute, fixed).When would you use top, left, right 
and bottom?
Answer:
Static represents default position of the element. Relative is used to move the element from his original position and here we
use top,left right and bottom to move the element,absolute is used to move elements relative to its parent and if there is no 
parent then it is moved to relative to its nearest ancestor .Fixed is used to fix an element at a position on the web page.
